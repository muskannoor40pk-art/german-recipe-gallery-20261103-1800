## Overview
The Recipe Gallery is a sleek, single-page application designed for food enthusiasts and developers in the DACH region. It provides a clean, distraction-free interface to browse culinary inspirations. Built with performance in mind, this project proves that complex functionality doesn't require heavy frameworks.

## Features
*   **Responsive Design:** Optimized for mobile, tablet, and desktop using CSS Grid and Flexbox.
*   **Instant Search:** Filter recipes in real-time as you type.
*   **Category Filtering:** Easily navigate between cuisines, meal types, or dietary preferences.
*   **Detail Modal:** View ingredients and instructions in a clean, focused overlay without leaving the page.
*   **Zero-Dependency:** Pure Vanilla JavaScript for maximum speed and security.
